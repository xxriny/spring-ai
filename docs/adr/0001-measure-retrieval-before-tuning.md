# ADR 0001: 실측 근거로 검색 단계를 조정한다

- 저자: Codex
- 날짜: 2026-10-23

## 상태

적용. HTML 중복 추출은 수정했으며 변경 후 검색 품질은 아직 재측정하지 않았다.

## 컨텍스트

### 문제 정의

#### 배경

pgvector·BM25 Top-10을 RRF로 합친 뒤 Qwen3 리랭커와 passage Top-3을 적용한다. [첫 실측](../LocalRetrievalEvaluation2026-10-23.md)에서는 RRF의 근거 문구 Hit@1이 75.0%, 재정렬과 최종 passage는 각각 50.0%였다.

#### 조건

생성 모델은 미정이다. 공식 Spring AI 문서 4쪽·고정 질문 16개와 로컬 임베딩·리랭커를 사용한다. 기존 벡터 색인은 ETL 코드 변경만으로 갱신되지 않는다.

#### 목표

근거 누락이 수집·후보 검색·재정렬·passage 선택 중 어디서 생기는지 구분하고, 변경 전후를 같은 기준으로 비교한다.

#### 목표 아닌 것

이번 단계에서 생성 답변 품질을 주장하거나, 증거 없이 리랭커·Top-k·임계값을 바꾸지 않는다.

#### 평가

원시 후보·점수·최종 passage를 사례별로 확인한다. `etl-03`은 중복 의존성 청크가 상위를 차지했고, `pg-02`는 정확한 문자열 기준이 부분 근거를 누락으로 집계했다. 검색 지표는 사람이 판정한 답변 가능성과 구분한다.

## 결정

### 해결 방안

#### 설계

HTML의 중첩 블록 텍스트를 한 번만 읽고, 한 문서 안에서 제목·본문이 모두 동일한 절만 중복 색인하지 않는다. 다른 내용의 동명 절은 유지한다. 품질 변경은 고정 질문·근거 기준의 변경 전후 실측으로 판단한다.

#### 구현

`KnowledgeService.extractHtml`에 중첩 요소 제외와 동일 절 제거를 적용했다. 두 원인을 별도 실패 테스트로 재현한 뒤 수정했으며, 전체 Maven 테스트 49개가 통과했다. 기존 문서는 별도 재색인이 필요하다.

## 결과

### 코드 리뷰

독립 코드 리뷰는 미실시다. 검토할 핵심은 동일한 제목·본문이 다른 상위 절에 반복될 때 하나만 남기는 규칙이 근거 문맥을 잃지 않는지 여부다.

### 타임라인

#### 로드맵

공식 문서를 백업 후 재색인하고 동일한 16문항으로 검색 품질을 재측정한다. 변경 후 품질은 현재 미측정이다.

#### 대안

- 리랭커 교체·Top-3 확대: 중복 색인 원인과 context 비용을 그대로 둔다.
- 평가 문구만 완화: 실제로 빠진 `etl-03` 근거를 복구하지 못한다.
